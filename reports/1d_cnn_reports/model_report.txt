----------------------------------------------------------------------
5. INTERPRETATION
----------------------------------------------------------------------
  Both feature-selection strategies feed the SAME 1-D CNN architecture, so
  the performance gap between them isolates the effect of feature selection
  method rather than any difference in model capacity. SelectKBest is a
  univariate filter (ranks each feature independently of the others using an
  F-test against the target), while RFE is a wrapper method that iteratively
  removes the least useful feature(s) according to a fitted Ridge model, so it
  can capture feature interactions that a univariate filter misses. In this run,
  RFE outperformed SelectKBest by roughly 21% lower validation RMSE.
  Note this differs from the classical linear-model comparison on this project,
  where SelectKBest previously outperformed RFE with a plain LinearRegression
  estimator; here RFE uses a regularized Ridge estimator (which is more stable
  with many rare one-hot categories) and feeds a non-linear CNN, both of which
  change which features end up being most useful downstream.
